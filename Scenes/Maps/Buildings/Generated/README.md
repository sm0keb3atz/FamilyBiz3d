# Generated buildings

Save new building scenes in this folder after using
`BuildingGeneratorTemplate.tscn`.

1. Open the template and immediately use **Save As** so the template remains
   clean.
2. Expand the `profile` resource in the Inspector and choose the footprint,
   stories, preset, palette, prop density, entrance, and seed.
3. Press **Generate / Regenerate** on the root node.
4. Put unique hand-authored signs or props under `ManualDetails`; regeneration
   never replaces that subtree.
5. Press **Bake To Editable Nodes** only when the procedural controls are no
   longer needed.
